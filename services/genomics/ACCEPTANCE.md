# Genomics Engineering Acceptance

Engineering scope implemented in Python v1. Required university scientific review, independent reference comparison, performance acceptance and formal contract freeze are deferred until all A–N services are engineered, per project owner direction.

Engineering gates: canonical artifact roundtrip and integrity; bounded QC/ORF/GFF3/VCF operations; aggregate privacy behavior; registry/schema/compile/lint/test/benchmark CI. Passing these gates is not scientific acceptance.


## Agentics scientific acceptance

- [ ] Reference-build, coordinate, allele and sample semantics documented: Genetics, population genetics, probability/statistics, discrete algorithms, experimental design, causal inference, measurement error and variant evidence.
- [ ] Pre-generation/input audit checks metadata, data permission, schemas and reference compatibility.
- [ ] Independent checks validate normalization, reference integrity and statistical claims.
- [ ] Uncertainty, population limitations, missingness and evidence class reported.
- [ ] Dataset and tool versions, checksums and lineage preserved.
- [ ] Privacy, licensing and leakage controls demonstrated.
- [ ] Engineering and scientific acceptance reported separately.
