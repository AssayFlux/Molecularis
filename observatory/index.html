Observatory system notes

System & methodology

Observatory is a read-only, browser-based repository instrument in this initial release. It makes no writes to the repository and does not trigger training, simulations, deployment or external scientific tools.

Data sources

Capability registryRaw YAML on CORE

RefreshManual / on load
PersistenceNone

Run locally

From the repository root:

python -m http.server 8765 --directory observatory

Then open http://localhost:8765. Requires an internet connection for live GitHub data. A local snapshot fallback is not bundled.
